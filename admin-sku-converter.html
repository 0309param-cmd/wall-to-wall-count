SKU Master → sku-master.json Converter

In Excel, from your SKU master sheet, save/export as CSV with exactly these column headers in row 1: code, description, qtyPerBox. Then upload that CSV here. It will generate the sku-master.json file — download it and replace the placeholder file of the same name in your project folder, then redeploy (see README-SETUP.md).
